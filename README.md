# CarroIA - Sistema de Manutenção de Veículos

Sistema web para gerenciamento de manutenções de carros.

## 🚀 Deploy no Render

1. Crie uma conta no [Render](https://render.com)
2. Conecte seu repositório GitHub
3. Configure como **Web Service**
4. O Render detectará automaticamente as configurações

## 💻 Desenvolvimento Local

```bash
npm install
npm start
```

Acesse: http://localhost:3000

## 📱 Acesso pela Rede Local

Com o servidor rodando, acesse de qualquer dispositivo na mesma rede usando seu IP local:
```
http://SEU-IP:3000
```

## 🛠️ Tecnologias

- **Backend**: Node.js + Express
- **Banco de Dados**: SQLite (sql.js)
- **Frontend**: HTML + Tailwind CSS + JavaScript
